# Architecture Diagram Creation

Look at the Azure ARM deployment created by file `app/arm/deploy-arm.sh`.

Please create both a png file and Mermaid file that visualizes
the architecture of the ARM-deployed solution.

Feature both the PaaS services as well as the Networking aspects of the deployment.

Save the png as file `docs/img/architecture.png' and the Mermaid file
as `docs/architecture.mmd'.
